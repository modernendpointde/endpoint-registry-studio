# Sample Workspaces

Use **Open** in Endpoint Registry Studio to load a sample.

| File                                                        | Contents                                             |
| ----------------------------------------------------------- | ---------------------------------------------------- |
| `01-hklm-dword.registry-workspace.json`                     | HKLM DWORD                                           |
| `02-unicode-string.registry-workspace.json`                 | Unicode string                                       |
| `03-hkcu-signed-in-users.registry-workspace.json`           | HKCU, currently signed-in users, SYSTEM              |
| `04-hkcu-all-profiles-default-user.registry-workspace.json` | HKCU, all existing profiles and Default User, SYSTEM |
| `05-value-deletion.registry-workspace.json`                 | Delete an HKLM value                                 |
| `06-win32-revert.registry-workspace.json`                   | Win32 App DWORD, uninstall deletes the value         |

All sample values use `Software\EndpointRegistryStudio\Samples\…`.
